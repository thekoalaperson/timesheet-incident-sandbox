Integrate through the monitor API

An investigator needs only the monitor API. Start a run, retain its runId, and scope alerts, logs, service context, and workflow snapshots to that ID. Seeds and noise make workloads replayable. Context exposes observed records and correlations; independent grading uses a separate maintainer oracle, never this public page or case metadata.

Workload completion and observed health are separate from the quality of an investigator’s explanation. Compare diagnoses and proposed changes through independent grading, then rerun the same workload to verify a fix.

Candidate verification and handoff notes
Candidate fixes must leave benchmark/, datadog-mock/, the Java benchmark harness package, and WorkflowControlTest unchanged. To audit the actual committed Git diff, run the verifier with --candidate-repo PATH --base-ref REF --head-ref REF (head defaults to HEAD). It rejects protected harness changes in verify-fixed mode. Without these flags it verifies domain behavior, but does not audit patch scope.
