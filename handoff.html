Verify the fixed scenarios

  1. Reset the demo before each scenario. Reset clears demo employees, time entries, and monitor observations.
  2. Run the baseline to confirm an 8-hour total and an OK monitor.
  3. Reset again, then run a regression scenario. Confirm the correct timesheet result and healthy monitor; inspect logs for supporting evidence.
  4. Use log evidence and the repository mapping to verify the code changes. The original three bugs are fixed; harder incident scenarios are planned and are not yet built.
